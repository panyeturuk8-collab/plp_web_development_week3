# Personal Budget Tracker (Week 3)

A styled HTML and CSS personal budget tracker featuring a structured expense form, an expense history table, collapsible usage instructions, and an embedded budgeting video.

## What Each File Does

- **`index.html`**: Houses the page header, collapsible `<details>` instructions, expense `<form>` with a category `<select>` dropdown, `<table>` of sample expenses, and embedded YouTube `<iframe>`.
- **`style.css`**: Applies the color palette, Google Fonts (`Plus Jakarta Sans` and `Inter`), form and button styles, table formatting, and CSS Box Model card spacing (`margin`, `padding`, `border`, and `border-radius`).
- **`README.md`**: Explains the project overview, file roles, and styling details for submission.

## Rubric Alignment

- **Intentional Color Palette**: Uses a slate-navy (`#1e293b`) primary brand color, emerald green (`#15803d`) action button, sky-blue (`#0284c7` / `#e0f2fe`) focus and hover highlights, and light neutral backgrounds (`#f1f5f9` / `#ffffff`).
- **Typography**: Pairs `Plus Jakarta Sans` for headings with `Inter` across body copy, form labels, inputs, buttons, and table cells, plus `tabular-nums` for currency alignment.
- **Table & Form Styling**: Configures `border-collapse: collapse`, cell and input padding, dark table header contrast, `tbody tr:nth-child(even)` alternating rows, row hover states, and button hover/focus states.
- **CSS Box Model**: Separates the header, instructions, form, and expense table into distinct cards using consistent `margin`, `padding`, `border`, and `border-radius`.
